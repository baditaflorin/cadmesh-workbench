# cadmesh-workbench

[Live GitHub Pages site](https://baditaflorin.github.io/cadmesh-workbench/)

Browser-first CAD, mesh repair, and photogrammetry-to-glTF workbench with a Docker compute API.

This repository is being actively scaffolded. The v1 architecture is GitHub Pages for the frontend and a Dockerized Go backend for heavyweight CAD, mesh, and photogrammetry jobs.

## Links

- Repository: https://github.com/baditaflorin/cadmesh-workbench
- Support: https://www.paypal.com/paypalme/florinbadita

## Quickstart

```sh
make install-hooks
make dev
make test
make build
make smoke
```
